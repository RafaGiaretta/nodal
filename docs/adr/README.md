# Registros de decisão de arquitetura

Cada decisão de arquitetura relevante vira um ADR curto nesta pasta, no formato de [Michael Nygard](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions).

Para registrar uma decisão nova, copie o [modelo](0000-modelo.md), use o próximo número livre e abra um PR. Um ADR aceito não é editado: se a decisão mudar, crie um novo ADR que substitui o anterior e atualize o status do antigo.

| [0004](0004-idioma-e-i18n.md)             | Interface em português com i18n pronta     | Aceito |
